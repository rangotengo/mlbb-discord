MLBB Tournament Bot

Discord connection

Paste the bot token from the Discord developer portal. It is stored in the operating system key store when that is available, and it is not written into the settings file.

Enable the Server Members and Message Content intents before inviting the bot.

Server selection

The bot creates the organiser role when it joins a server. Use the same role name here and in Discord.

Channel and permission checks run after the bot is online. A saved token is not the same as a connected server.

Challengermode access

Generate an application refresh key in the Challengermode developer dashboard. The bot only reads tournament data. Scores and registration stay on Challengermode.

Email setup

Verification codes are sent with a Google OAuth client. Leave the fields blank to keep the saved credentials. An empty test does not mean a code was sent.

Storage

SQLite is the desktop default. Only one app instance can use the file. PostgreSQL backups are not copied by the desktop app; use that server's own backup tool.

    Dashboard access

    The dashboard listens on this computer by default. Opening it from the app creates a one-time local session. Other devices need network access and a password.

    Network access requires a password. Loopback is not treated as a login, including when a reverse proxy connects locally.

    Checklist

    A failed step names the recovery action. Items that need the running bot stay "not checked" or "not available" until that check can actually run.
